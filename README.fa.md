# Codal Scraper 📊

ابزاری پایتونی برای جمع‌آوری و استخراج اطلاعات مالی و گزارش‌های منتشرشده در [Codal.ir](https://codal.ir).

> 🇬🇧 [English README](README.en.md)

---

## 📌 درباره پروژه

**Codal Scraper**
یک پروژه مستقل و آموزشی برای دریافت و جمع‌آوری اطلاعات مالی شرکت‌های پذیرفته‌شده در بازار سرمایه ایران از سامانه کدال است.

هدف بلندمدت پروژه این است که بتواند اطلاعات مالی شرکت‌ها را به‌صورت خودکار جمع‌آوری کرده و در مراحل بعدی برای:

- تحلیل بنیادی
- محاسبه نسبت‌های مالی
- مقایسه شرکت‌ها
- رتبه‌بندی شرکت‌ها
- تحقیقات مالی و دانشگاهی
- ساخت دیتاست برای Machine Learning

استفاده شود.

---

## ✨ قابلیت‌ها

- دریافت اطلاعیه‌ها و گزارش‌های مالی از Codal
- پشتیبانی از گزارش‌های سالانه و میان‌دوره‌ای
- دریافت داده در قالب JSON و XML
- جستجو بر اساس نماد شرکت
- امکان دریافت دسته‌های مختلف اطلاعیه‌ها
- تأخیر تصادفی بین درخواست‌ها برای کاهش فشار روی سرور
- مدیریت خطای HTTP 429 (Too Many Requests)
- دانلود کنترل‌شده و موازی گزارش‌ها
- ذخیره اطلاعات هر نماد در پوشه جداگانه
- جلوگیری از دانلود مجدد فایل‌های تکراری
- نرمال‌سازی حروف فارسی و عربی
- سازگار با Python 3.10+

## 🔍 API کدال

یکی از بخش‌های مهم این پروژه استفاده از API داخلی جستجوی کدال است:

```text
https://search.codal.ir/api/search/v2/q
```

این endpoint در حال حاضر مستندات رسمی و عمومی مشخصی ندارد.

### API چگونه پیدا شد؟

این API از طریق **Reverse Engineering / Network Inspection** سامانه کدال شناسایی شده است.

فرآیند کلی:

1. ورود به Codal.ir
2. باز کردن Developer Tools با `F12`
3. رفتن به بخش `Network`
4. انجام یک جستجو در سایت
5. مشاهده درخواست‌های HTTP ارسال‌شده توسط سایت
6. پیدا کردن درخواست مربوط به Search API
7. بررسی URL، Query Parameters و Response
8. بازسازی همان درخواست در Python

بنابراین منظور از Reverse Engineering در این پروژه، مهندسی معکوس کد یا سرور کدال نیست؛ بلکه **بررسی نحوه ارتباط Frontend وب‌سایت با API از طریق Network Requests** است.

## 🧩 پارامترهای مهم API

برخی پارامترهایی که در درخواست‌های API استفاده می‌شوند:

| Parameter | توضیح |
|---|---|
| `Symbol` | نماد شرکت |
| `Category` | دسته اطلاعیه |
| `PageNumber` | شماره صفحه |
| `Audited` | گزارش‌های حسابرسی‌شده |
| `NotAudited` | گزارش‌های حسابرسی‌نشده |
| `Mains` | اطلاعیه‌های اصلی |
| `Childs` | اطلاعیه‌های فرعی |
| `Length` | طول دوره مالی |
| `search` | عبارت جستجو |

> ساختار API ممکن است در آینده توسط Codal تغییر کند.

## ⚠️ Rate Limiting

کدال برای تعداد زیاد درخواست‌ها محدودیت‌هایی اعمال می‌کند و در صورت ارسال درخواست‌های زیاد ممکن است خطای:

```text
HTTP 429 - Too Many Requests
```

دریافت شود.

برای کاهش این مشکل، پروژه از روش‌هایی مانند:

- Random Delay
- Controlled Concurrency
- Retry
- Request Throttling

استفاده می‌کند.
