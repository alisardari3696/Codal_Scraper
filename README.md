# Codal Scraper 📊

A Python scraper for collecting financial reports and disclosure data from [Codal.ir](https://codal.ir).

## 📌 About

This project is an independent research and educational project for collecting public financial information from Codal.ir.

> The Codal search endpoint used by this project is undocumented and was discovered by inspecting the network traffic of the Codal website.
