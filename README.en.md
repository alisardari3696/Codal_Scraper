# Codal Scraper 📊

A Python-based tool for collecting and extracting financial data and disclosure reports from [Codal.ir](https://codal.ir).

> 🇮🇷 [نسخه فارسی](README.fa.md)

---

## 📌 About

**Codal Scraper** is an independent research and educational project for collecting public financial information from companies listed in the Iranian capital market through Codal.

The long-term goal of this project is to automatically collect financial data and use it for:

- Fundamental analysis
- Financial ratio calculation
- Company comparison
- Company ranking
- Financial and academic research
- Dataset creation for Machine Learning

---

## ✨ Features

- Scrape financial disclosures from Codal
- Support for annual and interim financial reports
- JSON and XML response handling
- Search by company symbol
- Support for different disclosure categories
- Randomized delays between requests
- HTTP 429 (Too Many Requests) handling
- Controlled concurrent downloads
- Separate folders for each company
- Duplicate download prevention
- Persian/Arabic character normalization
- Python 3.10+ compatibility

## 🛠️ Installation

Clone the repository:

```bash
git clone https://github.com/alisardari3696/Codal_Scraper.git
cd Codal_Scraper
```

Install the required dependency:

```bash
pip install aiohttp
```

---

## ▶️ Usage

Run the main script:

```bash
python codal_scrape.py
```

The program will ask for the company symbol.

For example:

```text
فملی
```

In versions that support it, you can also use:

```text
y
```

to request data for all available symbols.

## 📂 Output Structure

Downloaded data is stored inside the `codal_data` directory.

Example:

```text
codal_data/
├── فملی/
├── فولاد/
└── شستا/
```

Each company has its own directory containing its related reports and disclosures.

## 🔍 Codal API

One of the key components of this project is the use of Codal's internal search API:

```text
https://search.codal.ir/api/search/v2/q
```

This endpoint does not currently have clear, publicly available official documentation.

### How was the API discovered?

The endpoint was identified through **reverse engineering / browser network inspection**.

The general process is:

1. Open Codal.ir
2. Open Developer Tools using `F12`
3. Go to the `Network` tab
4. Perform a search on the website
5. Inspect the HTTP requests generated by the website
6. Identify the request related to the search API
7. Examine its URL, query parameters, and response
8. Recreate the same request in Python

In this context, **reverse engineering does not mean reverse engineering Codal's source code or server**.

It refers to analyzing the communication between Codal's frontend and its backend API through network requests.

## 🧩 Important API Parameters

Some of the parameters used by the API include:

| Parameter | Description |
|---|---|
| `Symbol` | Company symbol |
| `Category` | Disclosure category |
| `PageNumber` | Page number |
| `Audited` | Audited reports |
| `NotAudited` | Unaudited reports |
| `Mains` | Main disclosures |
| `Childs` | Child disclosures |
| `Length` | Financial period length |
| `search` | Search query |

> The API structure may change in the future if Codal modifies its internal systems.

## ⚠️ Rate Limiting

Codal may apply rate limits when receiving a large number of requests.

Excessive requests can result in:

```text
HTTP 429 - Too Many Requests
```

To reduce the probability of hitting rate limits, the project uses techniques such as:

- Random delays
- Controlled concurrency
- Retry mechanisms
- Request throttling
